## Main paragraph-level dataset
This is a paragrpah-level dataset of Classical Chinese prose, containing 6000 paragrpahs from Classical Chinese prose of various dynasties. 
'all_splits.csv' is the full source table
| split | rows |
|---|---:|
| train | 4800 |
| dev | 600 |
| test | 600 |
| total | 6000 |
Samples are divided into 6 paradigms: Pre-Qin philosophers' prose, Qin-Han-Wei-Jin prose, Tang prose, Song prose, Ming Xiaopin prose, Qing Tongcheng-school prose.Each paradigm has 1000 samples overall and is balanced across the three splits.
